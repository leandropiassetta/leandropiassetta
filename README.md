## 🚀 Featured Projects

### 🍎 [Fruit Store API](https://github.com/leandropiassetta/fruit-store-api)

Production-oriented REST API developed in Go using Clean Architecture and Hexagonal Architecture.

**What this project demonstrates:**

- Separation between domain, application, ports, and infrastructure adapters
- JWT authentication and role-based authorization
- PostgreSQL persistence with versioned migrations
- Redis caching with automatic invalidation
- Event-driven communication using Redis Streams
- Independent asynchronous consumer with a separate database
- Unit tests using in-memory repositories
- Complete local environment with Docker Compose

**Stack:** Go, PostgreSQL, Redis, Redis Streams, JWT, Docker, Clean Architecture

---

### ⚙️ [Go SQS Worker and AI Architecture Challenge](https://github.com/leandropiassetta/chatbot-technical-challenge)

Production-oriented solution involving a concurrent Go worker, AWS SQS, resilient distributed processing, and Generative AI architecture.

**What this project demonstrates:**

- Concurrent AWS SQS worker implemented in Go
- Batch processing and long polling
- Controlled concurrency and graceful shutdown
- Retry, exponential backoff, idempotency, visibility timeout, and DLQ strategies
- Message deletion only after successful processing
- Automated tests using an in-memory SQS implementation
- Architecture involving Lambda, SNS, S3, KMS, N8n, and external APIs
- LLM evaluation, hallucination mitigation, and deterministic guardrails

**Stack:** Go, AWS SQS, Lambda, SNS, S3, KMS, N8n, LLMs, Generative AI

---

### ✅ [JTech Tasklist Fullstack](https://github.com/leandropiassetta/fullstack2)

Multi-user task management platform with a Java 21 and Spring Boot backend integrated with a Vue 3 frontend.

**What this project demonstrates:**

- Backend architecture based on Ports and Adapters
- JWT authentication and refresh-token flow
- Resource ownership and multi-user authorization
- PostgreSQL persistence with Spring Data JPA
- Vue 3 frontend with TypeScript and Pinia
- Axios interceptors with a queue for concurrent token refresh requests
- Backend and frontend automated tests
- Docker-based PostgreSQL environment

**Stack:** Java 21, Spring Boot, Spring Security, PostgreSQL, Vue 3, TypeScript, Pinia, Docker
